## Preparation

Run `node scripts/prepare-garments.mjs` with the installed project dependencies.
`sketchfab-garments.mjs` checks SHA-256 source fingerprints before applying its
reviewed sewing-piece assignments. Both original GLBs remain unchanged.
They are kept locally and excluded from Git because the Sites source repository
rejects the full-resolution upload size. To reproduce preparation in a fresh
checkout, download the GLB versions from the source links above and place them
under the exact supplied filenames. The optimized GLBs, masks, audits and source
fingerprints are versioned; regular builds and tests do not need the originals.

Changes: original colors/textures replaced with editable fabric; all node
transforms baked; mirrored sleeve and torso UVs separated into independent zones;
torso split into front, back and side panels with interpolated normals; scale
normalized; indexed geometry reduced with UV-aware simplification and locked
boundaries; independent 4K masks generated. The camibuso's dense individual stitch
tubes are omitted, preserving its complete fabric shell, silhouette and hems.
Author, source, license and modifications also ship in exported project credits.

The old MakeHuman OBJ files are retained only as historical sources. Neither is
used by the pipeline or the application anymore. Credits above were checked
against the embedded GLB metadata and the official Sketchfab API on 2026-09-06.
